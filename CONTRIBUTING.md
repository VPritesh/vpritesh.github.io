# Contributing

Thanks for your interest in contributing!

## Code of Conduct

Please maintain a respectful, constructive, and inclusive environment.

## Found a Bug or Improvement?

Feel free to open an issue or submit a pull request:

1. **Fork** the repository
2. **Create a branch** for your feature or fix (`git checkout -b feature/improvement`)
3. **Commit your changes** (`git commit -m 'feat: improve typography and contrast'`)
4. **Push to the branch** (`git push origin feature/improvement`)
5. **Open a Pull Request**

## Development

```bash
# Install dependencies
npm ci

# Start local development server
npm run dev

# Run production build and typechecks
npm run build
```
